## 2026-1 — CADe

Durante o quinto semestre, continuei na equipe **SoftWorksAPI**, em parceria com uma unidade do Exército Brasileiro localizada em Caçapava, que atuou como cliente.

Nosso desafio foi desenvolver uma aplicação capaz de interpretar arquivos de arquitetura urbana e extrair o máximo possível de informações das plantas.

Nossa aplicação, chamada **CADe**, utiliza bibliotecas Python para interpretar e extrair informações de arquivos CAD. Posteriormente, essas informações são encaminhadas ao Ollama, responsável por processá-las e gerar relatórios.

**Vídeo de utilização:** [Assistir no YouTube](https://www.youtube.com/watch?v=LGW3GAbyMMo)

**Repositório:** [CADe](https://github.com/SoftWorksAPI/CADe)

### Tecnologias utilizadas

- **Ollama:** utilizado como assistente de Inteligência Artificial para processar as informações extraídas e elaborar relatórios.
- **MySQL:** utilizado para armazenamento de projetos e relatórios.
- **Python:** utilizado para leitura das plantas e extração de informações dos elementos.
- **ezdxf:** biblioteca Python utilizada para leitura e manipulação de arquivos CAD.
- **React:** desenvolvimento da aplicação no modelo SPA.
- **HTML:** estruturação das páginas.
- **CSS:** estilização da aplicação.
- **JavaScript:** interatividade e dinamismo das páginas.
- **TypeScript:** utilizado em conjunto com o ecossistema JavaScript.
- **Jira:** organização e gerenciamento das tarefas.
- **GitHub:** versionamento e gerenciamento do código.

### Contribuições pessoais

Atuei como **Product Owner (PO)** e também participei do desenvolvimento da aplicação, com foco na utilização de Python, especialmente da biblioteca ezdxf para leitura e extração de dados de plantas CAD.

### Hard Skills

- **Python:** aprimoramento das habilidades de programação e utilização de bibliotecas especializadas.
- **ezdxf:** experiência com leitura e extração de informações de arquivos CAD.

### Soft Skills
